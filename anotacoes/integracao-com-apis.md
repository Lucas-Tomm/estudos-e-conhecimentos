# Integração com APIs

Anotações de estudo em andamento sobre integração com APIs e comunicação entre sistemas.

## Motivo do estudo

Estou organizando este conteúdo porque tive contato com integrações na prática e quero reforçar os conceitos para entender melhor cada etapa, consultar quando tiver dúvidas e evoluir com mais segurança.

## Objetivo

Registrar os principais conceitos sobre APIs, consumo de dados e integração entre sistemas.

## Conceitos principais

API é uma forma de comunicação entre sistemas. Ela permite que uma aplicação envie, busque, atualize ou remova informações de outro sistema por meio de requisições.

## Tópicos em estudo

* URL base e endpoint
* Métodos HTTP: GET, POST, PUT/PATCH e DELETE
* Request e response
* Dados em formato JSON
* Headers e body
* Query parameters
* Autenticação com API Key e Bearer Token
* Status codes como 200, 201, 400, 401, 403, 404 e 500
* Cuidados com tokens, chaves de API e informações sensíveis

## Exemplo de lógica

```text
Método: POST
Endpoint: /clientes
Headers: Content-Type: application/json
Body: dados do cliente em JSON
```
