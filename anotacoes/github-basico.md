# GitHub Básico

Anotações de estudo em andamento sobre GitHub, organização de projetos e versionamento.

## Motivo do estudo

Estou organizando este conteúdo para aprender melhor o uso do GitHub, registrar minha evolução e usar a plataforma como portfólio inicial de aprendizado em tecnologia.

## Objetivo

Registrar os principais conceitos sobre GitHub, organização de repositórios, documentação e controle de alterações.

## Conceitos principais

GitHub é uma plataforma usada para guardar, organizar e compartilhar projetos, estudos, códigos e documentação. Ele também ajuda a registrar o histórico de evolução por meio de commits.

## Tópicos em estudo

* Diferença entre Git e GitHub
* Repositórios
* README
* Markdown
* Commits
* Mensagens de commit
* Branches
* Pull requests
* Merge
* Clone
* Push e pull
* Repositórios públicos e privados
* .gitignore
* Cuidados com senhas, tokens, API keys e arquivos sensíveis

## Exemplo de fluxo básico

```text
Criar ou editar arquivo
↓
Escrever uma mensagem de commit
↓
Salvar alteração no repositório
```

Exemplo de comandos para estudar futuramente:

```text
git status
git add .
git commit -m "docs: adicionar anotação"
git push
```
