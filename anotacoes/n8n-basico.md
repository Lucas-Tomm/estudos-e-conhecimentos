# n8n Básico

Anotações de estudo em andamento sobre automações com n8n.

## Motivo do estudo

Estou organizando este conteúdo porque já tive contato com workflows, nodes, testes e correções de erros em automações, mas quero reforçar os conceitos para entender os fluxos com mais clareza.

## Objetivo

Registrar os principais conceitos sobre n8n, workflows, nodes, automações e integrações.

## Conceitos principais

n8n é uma ferramenta de automação de processos que permite conectar sistemas, APIs e serviços por meio de fluxos chamados workflows.

## Tópicos em estudo

* Workflow como fluxo completo da automação
* Nodes como etapas do workflow
* Triggers para iniciar automações
* Input e output dos nodes
* Mapeamento de campos
* Expressões para usar dados dinâmicos
* Node HTTP Request para integração com APIs
* Nodes IF e Switch para condições
* Set/Edit Fields para organizar dados
* Code node para ajustes com JavaScript
* MySQL/Postgres para consultas em banco de dados
* Credentials para armazenar tokens, senhas e chaves de API

## Exemplo de lógica

```text
Trigger
↓
Organização dos dados
↓
HTTP Request para uma API
↓
Condição com IF
↓
Próxima ação
```
