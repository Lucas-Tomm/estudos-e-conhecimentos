# n8n Básico

Resumo dos meus estudos iniciais sobre automações com n8n.

## Conceitos principais

n8n é uma ferramenta de automação de processos que permite conectar sistemas, APIs e serviços por meio de workflows.

## Pontos estudados

* Workflow como fluxo completo da automação
* Nodes como etapas do workflow
* Triggers para iniciar automações
* Input e output dos nodes
* Mapeamento de campos
* Expressões para puxar dados dinâmicos
* Node HTTP Request para integração com APIs
* Nodes IF e Switch para condições
* Set/Edit Fields para organizar dados
* Code node para ajustes com JavaScript
* Credentials para armazenar tokens, senhas e chaves de API

## Exemplo de lógica

Um fluxo no n8n pode seguir esta estrutura:

```text
Trigger
↓
Organização dos dados
↓
HTTP Request para uma API
↓
Condição com IF
↓
Próxima ação
```

## Objetivo do estudo

Entender a lógica básica de automações, testes de execução, organização de dados e integração com APIs usando n8n.
